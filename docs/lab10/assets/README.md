# Logo cover laporan

`logo-ukwms.png` adalah logo Universitas Katolik Widya Mandala Surabaya yang diekstrak dari gambar cover pada dokumen referensi pengguna `Week_10_Laporan_ABSA_SATUSEHAT.docx`. Aset ini hanya dipakai untuk cover akademik laporan. Builder menyajikannya dalam skala abu-abu pada PDF sesuai permintaan pengguna.

Dokumen referensi hanya digunakan sebagai contoh tampilan. Isi penelitian, nama dosen Web Mining, nomor kelompok, dan identitas anggota pada dokumen tersebut tidak disalin ke laporan Web Service.

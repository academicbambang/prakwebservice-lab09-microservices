# Logo cover laporan

`logo-ukwms.png` adalah logo Universitas Katolik Widya Mandala Surabaya yang diekstrak dari gambar cover pada dokumen referensi pengguna `Week_10_Laporan_ABSA_SATUSEHAT.docx`. Aset ini hanya dipakai untuk cover akademik laporan. Builder mempertahankan warna asli logo pada PDF; teks laporan tetap hitam putih sesuai permintaan terbaru pengguna.

Dokumen referensi hanya digunakan sebagai contoh tampilan. Isi penelitian, nama dosen Web Mining, nomor kelompok, dan identitas anggota pada dokumen tersebut tidak disalin ke laporan Web Service.
